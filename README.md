# COMP0251 — Weakly-supervised 3D tumour segmentation from RECIST crosshairs

Turn sparse **RECIST crosshair** annotations (one long + short axis on a single
slice per lesion) into dense 3D tumour **pseudo-labels** by seeding the
**SAM2** video model and constraining its through-plane propagation, then train a
standard **nnU-Net** on those pseudo-labels alone — no dense manual tracing
anywhere in the pipeline. Accuracy is validated against expert dense manual
segmentations.

Pipeline in one line:

```
Horos .rois_series  →  label volume  →  SAM2 propagation + constraints  →  _clip pseudo-label  →  nnU-Net (5-fold CV)
                                                                                    └→ evaluated vs manual GT
```

All reported results use the **`sam2.1_hiera_small`** checkpoint.

## 1. Environment setup

Python **3.14**, conda-provided, everything else via pip.

```bash
conda env create -f environment.yml
conda activate comp0251
```

On a **CUDA** machine install the matching PyTorch build *before* the pip step
(the default wheels are CPU/MPS); see the header of `requirements.txt`.

### SAM2

SAM2 is **not bundled** — clone it into `./sam2`, install it (editable), and
download the checkpoint:

```bash
git clone https://github.com/facebookresearch/sam2.git ./sam2
pip install -e ./sam2                     # brings hydra-core, iopath, omegaconf
bash sam2/checkpoints/download_ckpts.sh   # or just fetch sam2.1_hiera_small.pt
```

Install / model details: https://github.com/facebookresearch/sam2
The pipeline is used with **`sam2.1_hiera_small`** (`--model small`).

### nnU-Net

`nnunetv2` is pinned in `requirements.txt` (so `pip install -r` covers it).
Set its data-root environment variables before any nnU-Net command:

```bash
export nnUNet_raw=$PWD/nnUNet_raw
export nnUNet_preprocessed=$PWD/nnUNet_preprocessed
export nnUNet_results=$PWD/nnUNet_results
```

Full docs: https://github.com/MIC-DKFZ/nnUNet

## 2. Input data layout

Each study is a folder pair under a dataset root (e.g. `samples/`):

```
samples/
  <case>_raw/                 # raw MR DICOM series (unannotated)
  <case>_roi.rois_series      # Horos "Save ROIs" vector export (RECIST crosshairs)
```

`<case>` looks like `brac62721a_00`. The 5-fold split
(`config/splits/splits_final.json`) is patient-grouped so a subject never spans
train/val.

## 3. Reproducing the main result (SAM2 `_clip` → nnU-Net, Dataset502)

Set `RAW` to your input folder — one containing a `<case>_raw/` DICOM subfolder
and a matching `<case>_roi.rois_series` per study (see §2) — and `OUT` to any
working directory for the generated files:

```bash
RAW=/path/to/dataset      # holds <case>_raw/ + <case>_roi.rois_series per study
OUT=/path/to/workdir      # generated labels, SAM2 input, and outputs go here
```

**Stage 1 — build labels + SAM2 input (local, CPU, seconds/case):**

```bash
scripts/build_dataset.sh "$RAW" "$OUT"
# preflight → roi_series_to_volume_split → prepare_sam2
# writes: $OUT/{labels, sam2_input, qc}/ and $OUT/cases.txt
```

**Stage 2 — constrained SAM2 propagation → `_clip` pseudo-labels (GPU):**

```bash
# local:
scripts/run_clip_local.sh "$OUT" small
# cluster (SGE array, one task per case):
qsub -t 1-$(wc -l < "$OUT/cases.txt") scripts/run_sam2_array.sh
# writes: $OUT/out/<case>_clip.nii.gz
```

**Stage 3 — assemble the nnU-Net dataset:**

```bash
python src/prepare_nnunet.py \
    --raw-root "$RAW" --labels-dir "$OUT/out" --label-suffix _clip \
    --cases "$OUT/cases.txt" --dataset-id 502 --dataset-name Tumour \
    --output nnUNet_raw
# then inject the patient-grouped split used for the reported results:
cp config/splits/splits_final.json nnUNet_raw/Dataset502_Tumour/splits_final.json
```

**Stage 4 — train nnU-Net, 5-fold CV (GPU):**

```bash
export nnUNet_raw=$PWD/nnUNet_raw nnUNet_preprocessed=$PWD/nnUNet_preprocessed nnUNet_results=$PWD/nnUNet_results
nnUNetv2_plan_and_preprocess -d 502 --verify_dataset_integrity
cp nnUNet_raw/Dataset502_Tumour/splits_final.json nnUNet_preprocessed/Dataset502_Tumour/splits_final.json

# cluster: edit DATASET_ID=502 in scripts/run_nnunet_train.sh, then
qsub -t 1-5 scripts/run_nnunet_train.sh          # 3d_fullres, folds 0–4
# or directly:
for f in 0 1 2 3 4; do nnUNetv2_train 502 3d_fullres $f; done
```

**Stage 5 — evaluate against the manual GT:**

```bash
python analysis/gt_compare.py       # Dice/precision/recall vs the manual segmentations → gt_report/
```

> **Dataset IDs.** `Dataset502_Tumour` is the reported build (SAM2 `_clip`, small
> model). `Dataset501` is an earlier pseudo-label build; `Dataset503_TumourEllipse`
> is the ellipse baseline. `scripts/run_nnunet_train.sh` defaults to `DATASET_ID=501`
> — set it to **502** to reproduce the reported CV.

## 5. Baseline and ablation

**Ellipse baseline (no SAM2)** — stack the fitted RECIST ellipse at every depth
with the same geometry as the clip:

```bash
scripts/build_ellipse_dataset.sh "$RAW" "$OUT" 503 TumourEllipse   # → Dataset503
```

**Constraint ablation** — one shared SAM2 pass per seed, four volumes differing
only in the toggled constraint (continuity gate / depth window / shape clip):

```bash
scripts/run_ablation_local.sh "$OUT" small
python analysis/ablation_compare.py        # scores each variant vs GT → gt_report/ablation/
```

## 6. Inference on a new scan

The trained nnU-Net segments a new study **directly from the MR volume — no RECIST
annotation is needed at inference** (the crosshairs are only used to build the
training pseudo-labels). This needs the trained weights present under
`nnUNet_results/Dataset502_Tumour/` — either from training (§3–4) or from a
released model archive (see *Trained model* below).

```bash
export nnUNet_results=$PWD/nnUNet_results

# 1. Convert the new scan's DICOM series to nnU-Net input (single channel _0000),
#    using the same reader as training so the voxel grid matches:
mkdir -p imagesTs
python - <<'PY'
import sys; sys.path.insert(0, "src")
import SimpleITK as sitk
from build_volume import read_dicom_series
img, _ = read_dicom_series("path/to/new_case_raw")      # a DICOM series folder
sitk.WriteImage(img, "imagesTs/newcase_0000.nii.gz")    # name MUST end in _0000.nii.gz
PY

# 2. Predict (ensembles the 5 CV folds):
nnUNetv2_predict -i imagesTs -o preds -d 502 -c 3d_fullres -f 0 1 2 3 4
# -> preds/newcase.nii.gz  (binary tumour mask on the input grid)
```

**Trained model.** The five fold checkpoints (~235 MB each, ~1.1 GB total) are too
large for the git repo, so they are hosted on UCL storage (access restricted to
UCL accounts):

- **Download:** https://liveuclac.sharepoint.com/:u:/s/COMP0251_Alasgarov_Nik_Aznan/IQB-ENdUNsepQ6LvuVppSa7EAUAISLGVRHxKoAjEktyYiwo?e=udhqFR
- **File:** `Dataset502_Tumour.zip` · SHA-256 `61044f5a3326078f3e81daa0391f0e0aefacf93d32a67f73ab135a6120b9382f`

Unpack it into `nnUNet_results/` so the layout is
`nnUNet_results/Dataset502_Tumour/nnUNetTrainer__nnUNetPlans__3d_fullres/fold_*/checkpoint_final.pth`
(alongside `plans.json` + `dataset.json`), then run the §6 prediction command.

## Notes

- **Model:** all reported numbers use `sam2.1_hiera_small`.
- **`preflight.py`** catches silent Horos/DICOM export mistakes — run it (it is
  stage 0 of `build_dataset.sh`) before trusting a new case.
- Every pipeline module in `src/` adds its own directory to `sys.path`, so the
  files must stay co-located; run scripts from the repo root.
